# gramafin.com: entity SEO audit (2026-11-08)

Scope: gramafin.com, www.gramafin.com, all 32 URLs in the sitemap (mostly on
app.gramafin.com), plus the Gramafin and Pakistan Mutual Funds API pages on
saadsalman.org. Search checks used a general web search engine, not Google, so
the indexing results need confirming in Google Search Console.

## Summary

The pieces are mostly there, but they're in the wrong places. The `/about` page
and every Help Centre footer say "built by Saad Salman", and saadsalman.org has
a good Gramafin node. But **the homepage, which should be Gramafin's home as an
entity, carries none of it**: no structured data, a one-word title, no creator
credit and no social links. Nothing independent mentions Gramafin yet, and a
search for the name finds nothing about it.

## Gaps, ranked by leverage

### 1. The homepage is empty as far as entities go (fix in `site`)
`https://gramafin.com/`
- No JSON-LD at all.
- `<title>` is just "Gramafin". The description, "Personal finance & wealth
  management in PKR", never says Pakistan or free.
- No "built by Saad Salman" in the footer, unlike every app.gramafin.com page.
- No links to Instagram or LinkedIn. The tagline doesn't appear anywhere.
- 428 words: under the 500-word floor for a key page.

**Fix:** a `WebApplication` node with `@id` `https://gramafin.com/#app`,
`creator`/`author`/`publisher` → `https://saadsalman.org/#person`, `sameAs`
(Instagram, LinkedIn, GitHub), `slogan`, `datePublished` 2026-06, `offers` 0
PKR, `featureList`. Title suggestion: *"Gramafin: Free Personal Finance & Net
Worth App for Pakistan"*. Description from `statements.gramafin_short`. Add
"built by Saad Salman" and social icons to the footer, and the tagline with its
English meaning to the hero.

### 2. Gramafin is described two different ways (fix in `site`, on both sites)
- saadsalman.org gives it `@id` `…/projects/gramafin/#software` and
  **`operatingSystem: "Web, Android, iOS"`. That's wrong: it's web only.**
- gramafin.com/about declares a `SoftwareApplication` with **no `@id`**, so
  nothing connects the two descriptions.

**Fix:** both sites use `@id` `https://gramafin.com/#app` for the app.
saadsalman.org changes `operatingSystem` to `Web`, and both list the same `sameAs`.

### 3. Help Centre: 25 articles with the same title and description (fix in `site`)
Every `/help/*` page has `<title>Gramafin</title>` and the same description, with
no canonical and no JSON-LD. These are the pages most likely to rank for
"how to track PSX / mutual funds in PKR". Right now they look like duplicates.
All are 136–345 words.

**Fix:** a title per article ("Adding a mutual fund — Gramafin Help"), the
description from the first sentence, a self-referencing canonical, and
`TechArticle` JSON-LD with `about` → `#app` and `author`/`publisher` → the
person `@id`. Expand the strongest articles (PSX prices, mutual funds/NAV, net
worth) past 500 words with real examples.

### 4. Content is split across two hosts with temporary redirects (fix in `site`)
gramafin.com serves only `/` and `/about`. Everything else, including
`robots.txt`, `sitemap.xml` and `/help`, **307-redirects** (temporary) to
app.gramafin.com. www.gramafin.com also returns 200 with no canonical, so it's a
duplicate of the homepage.

**Fix:**
- Make the redirects 301 (permanent), or serve the public pages (help, legal)
  on gramafin.com.
- 301 www → apex.
- Add `<link rel="canonical">` to every public page.
- Remove `/login` and `/signup` from the sitemap.
- Add `/cookies` if it's public.
- Verify both hosts in Search Console.

### 5. The Gramafin ↔ API link is only told from one side (fix in `site`)
saadsalman.org says it well ("I built it because Gramafin … needed a daily
NAV"), but gramafin.com never names the API.

**Fix:** add a sentence to `/about` and to *NAV updates and realized vs.
unrealized gains* ("NAVs come from the Pakistan Mutual Funds API, which Saad
built for Gramafin and open-sourced"), linking to the API page. Add `mentions`
→ the API's `@id`.

### 6. Social profiles aren't connected (fix in `reinforce`)
Instagram @gramafin.app and linkedin.com/company/gramafin exist, but the site
doesn't link them and search doesn't find them.

**Fix:** link them from the site (gap 1), add them to `sameAs`, and set each
profile's bio and website link (`statements.social_bio` → gramafin.com). The
LinkedIn page should list Saad Salman. Saad's personal LinkedIn should show
Gramafin as a project, linked to the company page.

### 7. Nothing independent mentions Gramafin (fix in `reinforce` / `content`)
A search for "Gramafin" returns drug names: Gramicidin, Gramcef, Glutafin. A
category search for a free PSX and mutual fund tracker lists Sarmaaya,
FinHisaab and SmartPSX, but not Gramafin. All current mentions are on sites you
own.

**Fix (legitimate only):**
- Launch listings: Product Hunt, Peerlist launchpad, AlternativeTo, and other
  relevant directories.
- A pitch to Pakistani tech press (ProPakistani, TechJuice) about the free
  MUFAP API and the app built on it.
- Honest answers in the communities where people ask how to track PSX and
  mutual funds.

### 8. No llms.txt (fix in `site`)
`/llms.txt` returns a 404. Add one with `statements.gramafin_long`, the
disambiguation line, the creator and the key help URLs.

## Classic diagnosis
- **Name search:** "Gramafin" → no results about the app. Search engines
  spell-correct it toward similarly named drugs, so the `disambiguation`
  statement matters.
- **`site:` check:** no results for gramafin.com or app.gramafin.com in the
  search engine used. This must be confirmed in Google Search Console.
  *Owner: is GSC set up for gramafin.com?*
- **Word counts:** homepage 428, /about 192, help articles 136–345. All are
  under 500.
- **Good:** pages are server-rendered (crawlable), images have alt text, OG
  images are present, and robots.txt correctly blocks the private app routes.
